# Skills de Superpowers (copia de respaldo)

Copia de cuatro skills de [obra/superpowers](https://github.com/obra/superpowers) (licencia MIT, ver `LICENSE-superpowers`) para la sesión diaria de Claude.

Si una sesión programada no carga el plugin Superpowers, lee aquí el `SKILL.md` que necesite la porción del día y síguelo igual:

- `test-driven-development/SKILL.md`: siempre que la porción cambie código.
- `verification-before-completion/SKILL.md`: antes de marcar una porción o decir que algo está listo.
- `systematic-debugging/SKILL.md`: cuando algo falle o se comporte raro.
- `requesting-code-review/SKILL.md`: al cerrar una tarea grande.
- `karpathy-guidelines/SKILL.md` (pautas de Andrej Karpathy, añadida por Arley el 23 nov 2026): siempre que la porción escriba o cambie código.

Son instrucciones de trabajo, no páginas del sitio; ninguna página las enlaza.
